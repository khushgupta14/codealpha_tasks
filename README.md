## 🗂️ Projects

### Task 1 — Responsive Image Gallery
A fully responsive image gallery with category filtering and lightbox view.

**Features:**
- Category filters (Nature, City, Animals)
- Lightbox with full-size image view
- Next/Prev navigation inside lightbox
- Keyboard support (Arrow keys + Escape)
- Responsive grid layout using CSS auto-fill
- Smooth hover transitions

**Tech:** HTML, CSS Grid, Vanilla JavaScript

---

### Task 2 — JavaScript Calculator
A clean, functional calculator with all arithmetic operations.

**Features:**
- Addition, Subtraction, Multiplication, Division
- Decimal point support
- Division by zero error handling
- Full keyboard support (0-9, operators, Enter, Escape)
- Responsive button layout using CSS Grid

**Tech:** HTML, CSS Grid, Vanilla JavaScript

---

### Task 4 — Music Player
A custom music player with playlist and audio controls.

**Features:**
- Play, Pause, Next, Previous controls
- Real-time progress bar with seek functionality
- Current time and duration display
- Volume control slider
- Clickable playlist with active song highlight
- Auto-advance to next song on completion

**Tech:** HTML, CSS, Vanilla JavaScript, Web Audio API
